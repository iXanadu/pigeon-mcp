Privacy Policy

pigeon — private Gmail MCP integration. Self-hosters: rewrite contact lines for your deployment.

Scope

This application is used solely by its operator, on Google accounts that the operator personally controls. There are no other users, and no third party is granted access.

What it accesses

With the account holder’s explicit consent, the application uses the Gmail API to read messages and threads, manage labels and drafts, send mail, and read basic account send-settings such as signatures. It requests only the scopes needed for those functions.

What it stores

The application stores OAuth refresh tokens so it can act without repeated sign-in, and a small record of recently sent messages used to avoid sending duplicates. Message content is not retained after a request is served.

How data is handled

Data is accessed only to fulfil requests made by the operator. It is not sold, rented, or shared with third parties, and is not used for advertising or to train machine-learning models. Credentials are stored with restricted file permissions on a server controlled by the operator.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Access can be revoked at any time from the Google Account permissions page, which immediately invalidates the stored tokens. Stored tokens are deleted when access is revoked or the integration is retired.
